# note Dark

note.com の記事閲覧画面と `editor.note.com` の編集画面をダークテーマにする Chromium 系ブラウザ拡張。記事本文だけでなく、コードブロック、インラインコード、引用、表、フォーム、メニュー、モーダル、note 内の埋め込みにも配色を適用する。中立的な背景色は一色に統一し、画像や動画そのものは作者の色を保つため反転しない。

## インストール

1. [Releases](https://github.com/drydeuterium/note-dark/releases) から最新版のZIPをダウンロードして展開する。
2. Chrome なら `chrome://extensions`、Edge なら `edge://extensions` を開く。
3. 「デベロッパーモード」を有効にする。
4. 「パッケージ化されていない拡張機能を読み込む」を押す。
5. 展開したフォルダを選び、note.com を再読み込みする。

ツールバーの拡張機能ボタンから、全 note タブとエディタのダークモードを即座にオン・オフできる。背景色は R・G・B をそれぞれ0〜255で指定でき、設定はブラウザ内に保存される。

## 設計上の境界

note.com 自身の iframe にはテーマを適用する。一方、YouTube、X、外部ストアなど別ドメインの埋め込み内部はブラウザの同一生成元制約と権限最小化のため変更しない。外枠と背景だけを暗くする。

note のクラス名にはビルドごとに変化するものがあるため、それだけに依存せず、note が公開ページで使用しているセマンティックな CSS 変数と安定した記事クラスを併用している。サイト更新後に白い領域が現れた場合は、その領域のセレクタを `dark.css` に追加する。
